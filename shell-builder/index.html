How to build an atom

  1. Read the atom’s atomic number. A neutral atom has that many electrons.
  2. Drag the gold e⁻ token onto an energy-level ring, tap a ring to add an electron, or use the level’s + button. Use − or tap a placed electron to remove one.
  3. Fill the ground-state arrangement. For the first 20 neutral atoms, level 1 fills to 2, level 2 to 8, level 3 to 8, then electrons begin level 4.
  4. Check your atom. You can correct mistakes and try again. A correct challenge atom earns up to 100 points; each wrong check reduces that atom’s reward by 20, and a hint reduces it by 25. Minimum reward: 20.

Why does potassium use level 4? Its nineteenth electron enters 4s before 3d. Potassium is 2–8–8–1; calcium is 2–8–8–2.

Shell capacity ≠ filling order. Maximum shell capacities follow 2n²: 2, 8, 18, 32. This game lets you try arrangements, then checks the correct ground state for H–Ca.

The circles organize electrons by principal energy level. Real electrons occupy orbitals and do not travel on circular tracks. This game checks populations, not the order in which you clicked.
